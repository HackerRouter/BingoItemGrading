# 用世界属性推导到达代价

## 背景

「走到最近的金矿」看起来应该按出生点枚举算平均距离，但出生点数量随世界大小无限，枚举既不可行，也无法回答改一个 spacing 参数后代价怎么变。

## 决策

不枚举出生点。到达代价由世界属性推导：

- 斑块密度与 `spacing` / `separation` 给出群系或结构的空间频率。
- 暴露密度给出「地表以上可见的该资源比例」。
- 出生点分布给出「出生在各群系的概率」。

期望距离是派生量，由上述属性算出并写入 `derived_from`，不作为原始输入。

## 后果

- 改一条世界属性（如结构 spacing），所有依赖它的到达代价一起变，且变化可解释。
- 派生量可以重算校验：同一组输入必须得到同一期望距离。
- 世界属性必须按地形包实测得到；虚构数据阶段用占位值，输出标记为虚构。

## 替代方案

按出生点采样估计平均距离：采样数决定误差，但误差无法与「统计本身不准」区分；且地形包一改就要重新采样。
