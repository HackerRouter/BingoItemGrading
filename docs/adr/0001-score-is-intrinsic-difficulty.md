# 分数是物品在地形包下的固有难度

## 背景

同一物品在不同 Bingo 卡上的实际获取难度不同：卡片决定了并行需求、路线拥挤、其他玩家抢点。把这些因素折进分数，会让分数随卡片变化，无法跨卡比较，也无法在调参时判断是地形变了还是卡变了。

## 决策

分数只描述「在给定地形包、随机出生、完美统计的假设下，拿到一件该物品所需的期望代价」。Bingo 卡、并行度、玩家水平都是下游输入，不进入分数。

## 后果

- 分数是地形包的属性，换卡不重算；换地形包整表重算。
- 卡片层面的难度由下游用「分数 + 卡片结构」现场合成，本模型不提供。
- 诊断输出必须能单独解释「为什么这个物品这个分」，不引用任何卡片信息。

## 替代方案

把并行度作为惩罚项乘进分数：需要预先知道卡片结构，分数无法独立复算；且卡片一变，全部 anchor 标定失效。
