# 玩家假设为完美统计与随机出生

## 背景

真实玩家的搜索策略有记忆、有偏好、有运气，把这层折进模型需要回放数据，而回放数据既难采集又随版本变化。同时，模型必须能回答「这个物品难在哪」，而不是「某个玩家上次怎么找到的」。

## 决策

模型假设玩家掌握全部世界统计、出生点在地形包允许的位置上均匀随机、不会针对某个物品定向搜索。搜索难度因此等于「统计触发的密度 + 顺路能覆盖的比例」，不包含玩家能力项。

## 后果

- 不存在绝对定向：任何来源的代价都是期望值，不是某个玩家的最优路线。
- 出生点不枚举，只用出生点分布与世界属性推导期望到达距离。
- 玩家能力不进入权重；若日后要按玩家水平分档，只能在下游对同一份分数做变换。

## 替代方案

引入玩家能力系数：需要标定人群分布，且会让分数无法独立复算；同一物品在不同人群下给出不同分，违背单一分数原则。
