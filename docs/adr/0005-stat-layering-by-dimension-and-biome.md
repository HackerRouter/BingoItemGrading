# 统计按维度与群系分层存储

## 背景

同一统计在不同粒度上的可用数据不同：矿石暴露密度在特定群系下有意义，结构间距只在地形包全局有意义。若只存一个粒度，要么丢失群系差异，要么在缺数据时整条查询失败。

## 决策

`world_stat` 以 `scope_level` 分层，细层优先、缺则回退：

```
biome_subject → biome → dimension → global
```

回退只降 `scope_level`，`subject` 与 `condition` 保持不变。命中即返回，并记录 `fallback_level`（0 表示命中细层）与该行 `confidence`。

带变体的群系（恶地、山地、深海等）统计时按变体采样，存储时合并到父群系，`between_variant_variance` 第一版留空。变体间的差异体现在 `confidence` 上，不体现在多行数据上。

## 后果

- 查询永远有结果（最差命中 `global` 或返回默认值并标 `fallback_level = none`），但结果的可信度随回退层数下降。
- 一处统计被多粒度引用时，改细层只影响细层查询。
- 变体细分留到诊断报警后再补，避免第一版数据量与统计工作翻倍。

## 替代方案

只存群系细层：缺数据的群系全部落空，无法给出分数；只存全局：群系差异（恶地金矿 vs 山地金矿）被抹平，而这是地形包难度的主要来源之一。
