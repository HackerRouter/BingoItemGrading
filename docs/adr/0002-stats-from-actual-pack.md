# 统计只取地形包实际数据

## 背景

原版统计数据在换地形包后不再成立：结构被删、群系被改、矿脉分布被调。沿用一组原版常数会让模型在地形包上系统性偏差，而偏差方向取决于该包改了哪些内容，无法用统一修正项补偿。

## 决策

所有世界属性来自当前地形包的实际数据，每条统计带 `pack_version`。没有对应统计时按回退链取更粗层，并在输出里标 `fallback_level` 与 `confidence`；不允许静默用原版值补齐。

## 后果

- 缺统计的表现在输出里可见，构成补数据的待办清单。
- 统计层与地形包版本绑定，换包触发全量重算与缓存失效。
- 第一版可以用虚构数据推进，但虚构数据的 `pack_version` 必须与真实包区分，且输出里带标记。

## 替代方案

以原版为基线，只记录地形包的增量：省数据，但任何一处地形修改都会让「基线 + 增量」的关系失效，且增量本身仍需要全量统计才能算出。
