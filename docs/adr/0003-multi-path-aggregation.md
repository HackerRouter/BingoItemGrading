# 路径代价按多路径聚合

## 背景

同一物品常有若干条互斥或互补的获取路径：红石粉可以挖矿、可以开地牢箱子、可以在地表沉船拿。只取最优单路径会低估代价——玩家并不知道哪条最优，且最优路径的覆盖率往往很低。

## 决策

聚合分两层：

- 域内并联：同一域内同 `group_id` 的 `alternative` 边按覆盖率加权调和平均聚合，`cost = 1 / Σ(coverage_i / cost_i)`，`cost_floor` 兜底。
- 域间取 min：跨域不并联，直接取各域聚合结果的最小值。

并联只在同域内成立：不同域的路径不能同时推进，把它们并联会算出「玩家同时在地下和地表」的错误结果。

## 后果

- 覆盖率是并联权重，不是概率折扣；`coverage` 低的路径仍然参与，只是贡献小。
- 同一 `group_id` 内混入跨域边是硬错误，装载时校验并报错。
- 诊断输出必须同时给出各路径代价与聚合结果，否则无法解释最终值。

## 替代方案

单条最优路径：实现简单，但会把「只有 5% 概率的顺手来源」当成主路径，且对覆盖率变化不敏感。
